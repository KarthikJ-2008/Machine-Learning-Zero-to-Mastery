# Introduction to Linear Regression

**Linear Regression** is a supervised machine learning algorithm used to predict continuous numerical values by finding a linear relationship between input and output variables.

- It assumes that there is a linear relationship between the input and output variables.
- Uses a best-fit line to make predictions.
- Commonly used in forecasting, trend analysis, and predictive modelling.

For example, suppose we want to predict a student's exam score based on the number of hours studied. As study hours increase, exam scores generally increase as well.

Here:

- **Independent variable (input):** Hours studied because it is the factor we observe or use to make predictions.
- **Dependent variable (output):** Exam score because it depends on the number of hours studied.

---

## 1. Best-Fit Line

In linear regression, the best-fit line is the straight line that best represents the relationship between the independent variable (\(X\)) and the dependent variable (\(Y\)). The goal is to minimize the difference between the actual data points and the predicted values generated by the model.

### Goal of the Best-Fit Line

The goal is to find a straight line that minimizes the sum of squared errors between the observed data points and the predicted values.

![Best Fit Line](https://www.iitianacademy.com/wp-content/uploads/2025/10/1_eRqtnWb6MRPnA22BIekSEw.png)

### Linear Regression Equation

**Y = mX + c**

Where:
- **Y** – Predicted output
- **X** – Input feature
- **m** – Slope of the line
- **c** – Intercept (value of Y when X = 0)

## 2. Types of Linear Regression

![Types of Linear Regression](https://media.geeksforgeeks.org/wp-content/uploads/20251212171556082327/types_of_linear_regression.webp)

1. **Simple Linear Regression:**  Uses one independent variable ($x$) to predict target ($\hat{y}$). 

2. **Multiple Linear Regression:** Uses two or more independent variables ($x_1, x_2, \dots, x_n$) to predict the target variable.


---

## 4. Evaluation Metrics

- **Mean Squared Error (MSE):** Measures the average of the squared differences between actual and predicted values.

- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted values.

- **Root Mean Squared Error (RMSE):** Square root of the Mean Squared Error. It measures prediction error in the same units as the target variable.

- **R-Squared (\(R^2\)):** Represents the proportion of variance in the dependent variable explained by the regression model.
